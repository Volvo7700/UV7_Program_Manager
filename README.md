# UV7 Program Manager

UV7 Program Manager is a Program Manager inspired by Windows 3.x. It can be used to organize important programs and/or as an alternative to the Windows start menu.

## Features
* Multi-Document Interface (MDI): Program links grouped in own program group windows
* Common format: Each program groups is defined by its own folder with shortcuts (LNK files) to the programs
* Desktop Mode: Use the program as a replacement for traditional, badly organized icons on the desktop
* Tray Icon: Fast access to program list via context menu

## Usecase
* As a Dashboard: Show all needed information at a glance on one screen
* Alternative to the Windows start menu
* Replacement for the Windows Desktop
